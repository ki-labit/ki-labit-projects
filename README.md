# Vendor Outstanding Balance Dashboard

## Overview

This project is a recreation of a financial reporting project completed during my internship. It demonstrates the use of SQL Server and Power BI to analyze vendor outstanding balances by Buyer Group ID.

Synthetic data was generated in a local SQL Server environment to recreate the original workflow while maintaining data confidentiality.

## Technologies

- SQL Server / SSMS
- Power BI
- SQL
- GitHub

## Workflow

SQL Transaction Data → SQL Reporting View → Power BI Dashboard

## Key Features

- Total invoice amounts by Buyer Group ID
- Outstanding balances by vendor
- Vendor and Buyer Group analysis
- Identification of high-balance accounts

## Repository Contents

- `SQL/` — Database, data-generation, and view scripts
- `Data/` — Synthetic transaction data
- `PowerBI/` — Power BI report
- `Documentation/` — Project documentation

## Note

All data in this repository is synthetic and does not contain confidential organizational data. The recreated dataset differs substantially from the original data used during my past experiences.
